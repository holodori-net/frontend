# 角色資料字典與轉換對照

`transformCharacters(database)` 回傳 `CharacterData[]`，保留全部角色，包含非可遊玩角色，並依 `order`、`id` 排序。卡片以 characterId 關聯角色 id，見 [cards.md](cards.md)。來源與適用快照見 [知識索引](../README.md)。

名稱、簡稱、粉絲名稱、介紹、留言及常規群組標籤轉為六語物件。選填文字 ID 為 null 時回傳 null；有文字 ID 時，每種設定語言皆須有非 null 文字，缺列或 null 文字使轉換失敗並回報來源欄位、角色 ID、語言與文字 ID。空字串及來源跳脫字元原值保留。

欄位名稱、SQLite 型別、主鍵、schema 宣告的關聯與轉換對應均為 **CONFIRMED**。用途尚未完整追蹤者另以信心標籤標示；宣告的關聯不等同 SQLite 外鍵約束。`✓` 表示已直接轉換或經查表產生回傳值，空白表示尚未轉換。

## 角色列表 payload

角色列表 reader 選取 `id`、`name`、`productionId`、`assetId`、`isPlayable`、`order` 與 `color1`，回傳 `CharacterListItemData[]`。保留全部角色與六語名稱；Nitro 於建置時產生共用靜態 `/data/characters.json`。角色頁以 `onServerPrefetch` 讀取初始資料，透過 `useState` 將資料保存在 HTML 的 Nuxt state，預設角色列表直接生成於 HTML。Hydration 透過 `getCachedData` 重用初始資料；從其他頁面切入時，以 `useLazyAsyncData` 先顯示頁首、標題與載入狀態，再取得靜態 JSON，失敗時提供重試。離線同步將此資料與角色頁保存於同一份快照。

## 成員主題 payload

**CONFIRMED**：`server/data/member-themes.ts` 重用完整角色 converter，選取角色 ID、六語名稱、來源排序、官方 `color1`～`color4` 與素材網址，回傳 `MemberTheme[]`。主題 ID 使用 `Character.id`，預設為みこ `chr-00015`；目前快照 62 位角色皆具備主色，包括 8 位非可遊玩角色。缺少主色時不收錄，選填色缺失時使用主色；色值轉為 `#RRGGBB`，格式錯誤回報角色與來源欄位。

`color1` 衍生頁面、surface 與 topbar 底色，`color2/3` 用於背景漸層、首頁裝飾與選單色票，`color4` 衍生互動主色、topbar 品牌文字與顯示設定圖示。亮暗配色透過共用規則生成，主要文字及按鈕文字含 hover／active 維持至少 4.5:1 對比。

素材用途由 `shared/theme.ts` 定義，保留 `assetId` 前導零：頁首 logo 與瀏覽器分頁 favicon 為 `img_card_thumb_${assetId}-4-cmmn-0000-00`，頭像為 `img_chr_icon_normal_${assetId}`，motif 使用 `img_chr_motif_icon_default_main_${assetId}` 與 `img_chr_motif_icon_light_main_${assetId}`；網址為 `https://assets.holodori.net/cdn/${name}/Texture2D/${name}.webp`。Logo 與 favicon 隨主題角色切換，缺圖或載入失敗時使用本機 `/icons/icon-192.png`。背景交錯排列兩種 motif，並以主題色套用透明遮罩；缺少素材時保留背景漸層與底色。

Nuxt plugin 以 `useAsyncData('member-themes', ...)` 保存主題 payload。靜態 HTML 使用みこ配色與中性 logo／favicon 占位；head 同步腳本使用同一 reader 提供的有效主題 ID 與 logo 網址，在首次繪製前套用 cookie 偏好的配色與 favicon。Favicon 標籤使用本機透明 SVG 並先於腳本解析；頁首 logo 占位保留 32px 寬高。Hydration 保留已套用的配色與 favicon，主題初始化後顯示背景圖案；logo 另等待頁首自身 mounted。偏好缺失、無效或讀取失敗使用預設；配色生成與 PWA manifest 直接使用同一 reader。

## LangCharacter

每筆代表一個角色相關文字 ID 在一種遊戲語言的內容。轉換 Character 的名稱、簡稱、粉絲名稱、介紹、留言及常規群組標籤對應文字。

**CONFIRMED**：主鍵為 `language, id`，目前快照 2412 筆。

| 轉換 | 來源欄位   | 型別        | 意義                                  | 關聯                                | 回傳對應                        | 備註／未轉換原因     |
| ---- | ---------- | ----------- | ------------------------------------- | ----------------------------------- | ------------------------------- | -------------------- |
| ✓    | `language` | TEXT        | 遊戲語言代碼                          | —                                   | 角色多語文字的語言 key          | 僅回傳設定的六語文字 |
| ✓    | `id`       | TEXT        | 文字 ID，供角色名稱及其他角色文字引用 | `Character 的文字 ID 欄位 → 本欄位` | 依 Character 的文字 ID 欄位查找 | 僅回傳設定的六語文字 |
| ✓    | `text`     | TEXT / null | 該語言的文字內容                      | —                                   | 角色多語文字的內容              | 僅回傳設定的六語文字 |
